## Prompt Formula

A useful AI music prompt usually combines:

`Genre + Mood + Instruments + Vocals + Structure + Tempo + Use Case`

Example:

> warm acoustic folk, nostalgic summer mood, fingerpicked guitar, soft female vocal, light percussion, simple memorable chorus, suitable for travel memories and lifestyle videos

You do not need to include every detail every time. Start with the sound you want, then add mood, instruments, vocal style, tempo, and where the track will be used.
