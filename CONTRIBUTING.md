# Contributing

Thanks for helping improve Awesome TopMediai AI Music Prompts.

This repository works best when every prompt has a real generated song result. Please do not submit copied prompts from other prompt libraries unless you own the rights and can show the generated TopMediai result.

## Submission Format

Use this format for every new song:

```markdown
### Song Title

**Genre:** Primary genre / secondary style  
**Mood:** Mood 1, mood 2, mood 3  
**Best for:** Creator use case 1, use case 2, use case 3  
**Song Type:** Vocal, instrumental, loop, remix, BGM, or sound cue

#### Prompt

> The exact prompt or style description used to generate the song.

#### Generated Result

[Listen on TopMediai](https://www.topmediai.com/app/ai-music/shared/00000000)

#### Try This Prompt

[Create a similar track with TopMediai](https://www.topmediai.com/app/ai-music/)
```

## Quality Checklist

- The TopMediai shared song link is public.
- The prompt is the prompt or style description used for the result.
- The genre and mood match what listeners will hear.
- The recommended use case is concrete, such as travel vlog, game trailer, study playlist, fashion edit, product launch, or meditation loop.
- No BPM, key, vocalist type, model version, or production detail is added unless it is known from the source prompt.

## Collection Guide

- Use `prompts/electronic-dance.md` for house, electropop, tropical house, dance pop, chiptune, and club-ready prompts.
- Use `prompts/soul-lofi-groove.md` for lo-fi, R&B, neo-soul, funk, jazz-influenced grooves, and bedroom pop.
- Use `prompts/rock-indie-alternative.md` for indie pop, indie rock, hard rock, surf rock, punk, metal, and guitar-led prompts.
- Use `prompts/acoustic-folk-roots.md` for folk, country, acoustic pop, roots, reggae, Latin acoustic, and warm storytelling prompts.
- Use `prompts/cinematic-ambient-creator-cues.md` for cinematic, orchestral, ambient, nature, meditation, transition, and sound-design prompts.

## Naming Notes

If two generated songs share the same title, keep the original title and add a short style label in parentheses, such as `(Folk-Pop Version)` or `(Deep House Version)`.
